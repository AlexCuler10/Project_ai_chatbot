AI Chatbot

A simple modern chatbot built with HTML, CSS, and JavaScript, integrated with Amazon Lex V1 using the AWS SDK for JavaScript. 
The chatbot allows the user to connect with the bot on their browser as an AI travel assistant. 

Team Group Members:
Kelvin Cuellar, Nathan Nelson, Alexandru Gonzalez, Kenny Ly, Brian Muramatsu


Features:

- Responsive chat UI 
- Real-time integration with Amazon Lex V2
- Typing indicator animation for better user experience
- Dark mode theme

Frontend
- HTML, CSS, JavaScript (Custom Web UI)
- AWS SDK v2
- Lex V2 Web Integration

Backend & AI
- Amazon Lex V2 (Chatbot interface & intent management)
- Amazon Bedrock (Generative AI via Claude v2)
- Amazon Titan Embeddings G1  (For vector indexing and document retrieval)
- Amazon S3 (Used for document storage)
- RAG (Retrieval-Augmented Generation) – Combines embeddings + LLM for contextual QA

Key Features
- Real-time fraud detection through chatbot
- Uses Lex intents 
- Queries knowledge base using natural language
- Typing indicator and responsive UI
- Embeds and indexes documents with Titan for precision
- Claude v2 for intelligent, natural-sounding responses
